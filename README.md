# 🕶️ فروشگاه عینک آفتابی

یک فروشگاه اینترنتی مدرن برای خرید عینک‌های آفتابی که با **React** و **Tailwind CSS** توسعه داده شده است.  
این پروژه دارای **سیستم احراز هویت کاربران** (ثبت‌نام، ورود و خروج) و **سبد خرید پویا** است و تجربه‌ای سریع، روان و کاربرپسند برای خرید آنلاین فراهم می‌کند.
[اسکرین‌شات از وبسایت](./public/screenshot.png)

## ✨ ویژگی‌های اصلی

- 🔐 **احراز هویت کاربران**  
  امکان ثبت‌نام، ورود و خروج کاربران با استفاده از Context API و مدیریت وضعیت احراز هویت.

- 🛒 **سبد خرید تعاملی**  
  افزودن، حذف و تغییر تعداد محصولات در سبد خرید، همراه با محاسبه خودکار مبلغ نهایی.

- 🕶️ **نمایش محصولات بر اساس دسته‌بندی**  
  نمایش محصولات در دسته‌بندی‌های مختلف مانند کلاسیک، اسپرت، لوکس، زنانه و مردانه.

- 🔍 **جست‌وجو و فیلتر پیشرفته**  
  امکان جست‌وجوی نام محصول و فیلتر بر اساس برند، رنگ، جنس و بازه قیمت.

- 📱 **طراحی کاملاً واکنش‌گرا**  
  رابط کاربری با استفاده از Tailwind CSS برای نمایش مناسب در موبایل، تبلت و دسکتاپ بهینه شده است.

- 🖼️ **صفحه جزئیات محصول**  
  نمایش تصاویر بزرگ‌تر، مشخصات فنی، نظرات کاربران و امکان افزودن محصول به سبد خرید.

- 📝 **فرم ثبت سفارش**  
  دریافت اطلاعات تحویل و نمایش خلاصه سفارش پیش از نهایی‌سازی خرید.

- ⚡ **عملکرد بهینه**  
  استفاده از React Hooks برای مدیریت state و بهینه‌سازی رفتار رابط کاربری.

## 🛠️ فناوری‌های استفاده‌شده

| فناوری | کاربرد |
| :--- | :--- |
| **React** | ساخت رابط کاربری با کامپوننت‌های ماژولار |
| **React Router** | مدیریت مسیرها و جابه‌جایی بین صفحات |
| **Context API** | مدیریت وضعیت سراسری مانند سبد خرید و احراز هویت |
| **Tailwind CSS** | استایل‌دهی سریع و مدرن با کلاس‌های کاربردی |
| **React Hook Form** | مدیریت فرم‌ها و اعتبارسنجی ورودی‌ها |
| **Vercel** | میزبانی و استقرار پروژه |

## 📂 ساختار پوشه‌ها
```text
src/
├── assets/        # تصاویر و فونت‌ها
├── components/    # کامپوننت‌های قابل استفاده مجدد
├── contexts/      # Contextهای سراسری
├── hooks/         # هوک‌های سفارشی
├── pages/         # صفحات اصلی برنامه
├── services/      # توابع مربوط به API
├── App.js         # کامپوننت اصلی
├── index.js       # نقطه ورود برنامه
└── index.css      # استایل‌های سراسری
# 1. کلون کردن مخزن
git clone https://github.com/MobinDe/sunglass-shop-react.git

# 2. ورود به پوشه پروژه
cd sunglass-shop-react

# 3. نصب وابستگی‌ها
npm install

# 4. اجرای پروژه در محیط توسعه
npm start
